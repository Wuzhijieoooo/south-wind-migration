# 南风来时

你不是候鸟，你是带它们北迁的南风。

这是一个面向 Web/H5 的无战斗迁徙轻 Roguelite 原型。玩家拖动生成短暂风路，引导鸟群穿过晨雾、夜航与雪岭，并在安全、体力和抵达数量之间做选择。

## 开发

```bash
npm install
npm run dev
```

验证命令：

```bash
npm test
npm run build
```
